| Наименование сущности | Описание | Связи с другими сущностями |
| :---:        |    :---:    |        :---: |
| Блюдо       | Кулинарное изделие, которое ресторан готовит из ингредиентов по технологической карте. Блюда образуют меню и входят в заказы, а также включены в номенклатуру. | Ингредиент (агрегация), заказ (агрегация), меню (агрегация), номенклатура (наследование) |
| Единица измерения | Величина, которая задаёт количество ингредиента | ингредиент (ассоциация), группа (агрегация) |
| Ингредиент | Компонент, из которого состоит блюдо | Единица измерения (ассоциация), блюдо (агрегация), технологическая карта (ассоциация), номенклатура (наследование), группа (агрегация), склад (ассоциация), инвентаризация (ассоциация) |
| Меню | Набор блюд, которые клиент может выбрать и заказать | Блюдо (агрегация), ресторан (композиция) |
| Ресторан | Заведение, в котором работают сотрудники, клиенты делают заказы, готовятся блюда | Сотрудники (агрегация), график работы (композиция), меню (композиция) |
| Склад | Помещение для хранения ингредиентов, не требующих особых условий | Сотрудники (агрегация), график работы (композиция), ингредиент (ассоциация), инвентаризация (ассоциация) |
| Технологическая карта | Документ с перечнем ингредиентов и последовательностью приготовления блюда | ингредиент (ассоциация), блюдо (композиция), технологическая карта (ассоциация) |
| Деньги | Средства для оплаты заказов и выплат сотрудникам | Банковский перевод / наличка (ассоциация), Оплата (ассоциация), списание (ассоциация), поступление (ассоциация), Банковские операции (ассоциация) |
| Сотрудник | Работник ресторана, склада или службы доставки | Ресторан (агрегация), склад (агрегация), график работы (агрегация), Контракт (агрегация), смена (композиция), заказ (ассоциация), заказ на производство (ассоциация), заказ на доставку (ассоциация), инвентаризация (ассоциация) |
| График работы | Расписание, определяющее время выхода сотрудников на работу | Сотрудник (агрегация), ресторан (композиция), склад (композиция), смена (зависимость) |
| Заказ | Перечень блюд, подобранных клиентом для приготовления | Сотрудник (ассоциация), клиент (композиция), блюдо (агрегация), заказ на производство (наследование), заказ на доставку (наследование), номенклатура (зависимость) |
| Заказ на производство | Заказ, который необходимо приготовить и принести в зал | Сотрудник (ассоциация), номер стола в зале (атрибут), клиент (ассоциация), заказ (наследование) |
| Заказ на доставку | Заказ, который необходимо доставить по определённому адресу | Сотрудник (ассоциация), адрес доставки (ассоциация), клиент (ассоциация), заказ (наследование) |
| Группа | Объединение сущностей одного типа. Группой в данной задаче является, например, группа единиц измерения или группа контрагентов | Контрагент (агрегация), единица измерения (агрегация), ингредиент (агрегация), блюдо (агрегация), инвентаризация (ассоциация) |
| Контракт | Соглашение, объединяющее контрагента, сотрудника и условия сотрудничества | Контрагент (агрегация), Сотрудник (агрегация) |
| Контрагент | Юридическое лицо, которые могут вести учет денежных средств. Каждый контрагент включается в какую-то группу | Контракт (агрегация), деньги (ассоциация), банковские операции (композиция), группа (агрегация), поступление (ассоциация), списание (ассоциация) |
| Банковские операции | Действия, связанные с движением денежных средств. В данной задаче рассматриваются две банковские операции, а именно списание, поступление | списание (наследование), поступление (наследование), оплата (ассоциация), контракт (ассоциация), деньги (ассоциация), контрагент (композиция) |
| Инвентаризация | Проверка фактического наличия и состояния имущества, денежных средств, запасов и т.д. | Склад (ассоциация), ингредиент (ассоциация), группа номенклатуры (ассоциация), сотрудник (ассоциация), номенклатура (зависимость) |
| Адрес доставки | Место, куда сотрудник (а именно курьер) должен доставить заказ | Заказ (ассоциация), Клиент (ассоциация), заказ на доставку (ассоциация) |
| Банковский перевод / наличка | Форма расчёта, применяемая при оплате в ресторане или за доставку | Оплата (ассоциация), деньги (ассоциация) |
| Оплата | Внесение денежных средств за предоставленную услугу | Деньги (ассоциация), Банковские операции (ассоциация), Банковский перевод / наличка (ассоциация), банковский перевод / наличка (зависимость) |
| Номенклатура | Перечень товаров и услуг, которые производит, продаёт или предоставляет организация. В данной задаче она обобщает ингредиенты, блюда, заказы | Ингредиент (наследование), блюдо (наследование), заказ (зависимость), инвентаризация (зависимость) |
| Поступление | Абсолютно все денежные средства, которые поступили на счет ресторана | Деньги (ассоциация), банковская операция (наследование), контрагент (ассоциация) |
| Списание | Исключение товаров, денег или долгов из финансового или бухгалтерского учета ресторана (компании) | Деньги (ассоциация), банковская операция (наследование), контрагент (ассоциация) |
| Клиент | Лицо, оформившее заказ на блюдо в ресторане или на доставку | Заказ (композиция), заказ на производство (ассоциация), заказ на доставку (ассоциация), адрес доставки (ассоциация) |
| Смена | Промежуток времени, фактически отработанный сотрудником | Сотрудник (композиция), график работы (зависимость) |
